## 第 1 节：写作纪律（最先读）

执行 Stage 6 / Stage 7 时，每写一句话都要先在心里过一遍以下七条问题（v1.2 增加第 7 条）：

1. **可替代性测试**：「如果换一个学生，这条建议需要改吗？」如果答案是「不需要」——重写。
2. **数字测试**：「这条建议里有可验证的数字吗？」如果没有——加上。
3. **动作测试**：「这条建议里的动词是『了解 / 关注 / 加强』这类模糊词吗？」如果是——改成「完成 / 上线 / 通过 / 提交」。
4. **来源测试**：「这条信息来自学生填写还是来自我的编造？」如果是编造——删除或改为「待补充」。
5. **温度测试**：「这条建议会让学生感到『被看见』还是『被工具化处理』？」如果是后者——加一句具体观察。
6. **时间锚点测试**：「这条建议的时间起点是 Stage 0 读到的真实当前学期吗？」如果不是——重写。
7. **反重复测试**（v1.2 新增，专为结尾段）：「这段写法如果同一个学生再来一次，会出现相同的句子吗？」如果会——重新挑维度、换细节、换句式。

把这七条贴在心里，整份计划书的质量会从 70 分跳到 90 分。

## 第 2 节：正文整体结构（v1.3）

无论学生选哪种风格 / 节奏，正文都按以下章节顺序展开。**章节顺序固定，不允许跳过任何一章**。

```
封面
学生画像速写（200 字内）
目录

第一章 个人现状盘点
第二章 目标岗位与行业深度画像
第三章 城市与组织画像
第四章 SWOT 与匹配度初判
第五章 三阶段目标（短期 / 中期 / 长期，含 OKR）
第六章 分学期行动计划（从 Stage 0 真实当前学期开始）
第七章 寒暑假专项行动计划
第八章 核心专业技能学习路线
第九章 可迁移能力培养路线
第十章 关键里程碑与时间表
第十一章 风险评估与备选方案
第十二章 评估机制与定期复盘

第十三章 反思与展望（v1.3 合并自 Stage 7 · 含 5 小节）
  1. 行业洞察与时代位置
  2. 心理准备清单
  3. 自我 vs 岗位匹配度诊断（含霍兰德匹配 / MBTI 互参）
  4. 人生红点对话
  5. 写给你的一封信

附录 方法论速查卡（OKR / 时间矩阵 / SCQA / 可迁移能力六大类 / 人生红点九类型）
```

**章节序号规则（v1.3 重要约定）**：

- 主章号用「第X章」中文格式
- **每一章内部的小节都从「1」开始**，不延续主章号
- 例：第二章下面的小节是「1. 岗位定义」「2. 所处行业宏观」「3. 真实工作内容」……
- 例：第九章下面的小节是「1. 六大类概览」「2. 岗位映射」「3. 自评矩阵」……
- 第十三章下面的 5 个小节同样从「1. 行业洞察与时代位置」开始

这样章节越多也不会出现「9.7」「9.8」「13.X.X.X」这种越编越长的尴尬。

## 第 3 节：各章写作要点

### 封面

包含：标题、署名（如学生愿意填）、专业 + 学校层次、生成日期、计划周期。
保留一句符合学生当下情绪状态的引言（不要套用『凡事预则立』之类的通用引言）。

### 学生画像速写

200 字以内，让学生第一眼感觉「这是写给我的」。引用 ta 在 Stage 1 / Stage 2 / Stage 4 中填的 1-2 项具体内容 + 一句关于 ta 当下处境的诚实观察。

### 第一章 个人现状盘点

按 Stage 1 收集到的维度逐项展开：学业表现、英语 / 资格证、实习与项目、社团 / 干部 / 公益经历、留白项。每节必须引用学生填写的**原文片段**。

### 第二章 目标岗位与行业深度画像（v1.4 写作要点扩充）

**目的**：把 Stage 3.1（行业）和 Stage 3.2（岗位）调研结果落地为学生能"看到、读懂、记住"的具体画像。每个意向岗位都单独建一节，**信息密度要够、要丰富**——这一章是整份计划书最厚重的部分，是后续所有规划的事实底盘。

**对每个意向岗位单独建一节**（章内编号从 1 开始），每一节内部按下列结构展开。**每个子项至少 80-150 字**，不允许只列子项标题就过去。

```
1. <意向岗位 1>

  1.1 岗位定义
      用 2-3 句话讲清：这个岗位每天对应做什么、产出什么样的东西、面向什么样的用户/客户、与相邻岗位的边界在哪里。
      避免词典式定义，要让学生读完能想象出 ta 入职后第一周的样子。

  1.2 所处行业宏观（来自 Stage 3.1）
      - 行业当前所处阶段（发展初期 / 成长期 / 成熟期 / 衰退期），用 1-2 个数据点支撑
      - 关键国家政策 / 法规驱动力或阻力（点名具体文件，如"十四五规划""新能源补贴""数据出境安全管理办法"等）
      - 市场规模量级 + 近 3 年增速
      - 行业头部公司 3-5 家 + 市场份额
      - 行业的主要商业模式（B/C/G 端、订阅 / 广告 / 撮合 / 项目制）

  1.3 真实工作内容
      用"一周时间分配"的方式拆解，更直观。例：
        - 周一 / 周二：与产品 PM 对齐需求（约 30% 时间）
        - 周三 / 周四：写代码 / 调试（约 50% 时间）
        - 周五：代码评审 / 周会 / 文档（约 20% 时间）
      或者按典型一天的时间轴展开：上午做什么、下午做什么、晚上是否常态加班。
      引用学生意向岗位调研中找到的具体 JD 任职职责片段做佐证。

  1.4 工作强度与压力来源
      - 加班节奏（995 / 996 / 双休 / 弹性 / 项目制爆肝）
      - 出差频率
      - 心理压力主要来源（KPI 压力 / 客户压力 / 上级压力 / 同事内卷 / 跨部门协作）
      - 行业里常见的 burnout 故事（用 1-2 句话讲一个真实案例 / 知乎吐槽）

  1.5 招聘门槛
      具体列出 4-6 条：
        - 学历底线（专科 / 本科 / 985-211 偏好 / 硕士起步 / 海外背景）
        - 专业卡控（哪些专业是默认通过 / 哪些会被卡）
        - 必备证书（如金融岗的 CFA / 教师岗的资格证 / 数据岗的 CDA）
        - 看重的实习 / 项目类型
        - 应届生招聘窗口（提前批 / 暑期实习 / 秋招 / 春招）
        - 加分项（竞赛 / 顶会论文 / 开源贡献 / 海外交换）

  1.6 核心技能（专业能力 + 可迁移能力，分两栏列出）
      左栏：硬技能（具体到工具 / 框架 / 方法论，避免说"扎实的专业基础"这种废话）
      右栏：软技能 / 可迁移能力（从 methodologies.md 卡片 1 六大类 22 子项中挑出该岗位最重要的 5 项）

  1.7 薪资区间
      - 应届起薪（按学生意向城市，月薪税前区间 + 中位数）
      - 工作 3 年薪资区间
      - 工作 5 年薪资区间
      - 薪资构成（base + 绩效 + 股票 / 期权 + 福利）
      数据来源标注（看准网 / 职友集 / Boss 直聘 / 学生意向公司近半年校招 package）。
      数据缺失则明确写"未查到可靠数据，建议你在 Boss 直聘按关键词检索近一月 JD 验证"。

  1.8 晋升路径
      用一张「初级 → 中级 → 高级 → 资深 → 专家 / 管理」的阶梯图。
      每一级标注：
        - 典型年限
        - 典型职级名（如 P5 / P6 / P7 或助理 / 主管 / 经理 / 总监）
        - 典型薪资跃迁
        - 关键升迁判据（业务结果 / 技术深度 / 团队规模 / 项目代表作）

  1.9 主要风险
      点名 3-5 项真实风险：
        - 行业周期性（如教培 2021 / 房地产 2023 这种系统性冲击）
        - 年龄歧视与 35 岁焦虑（这一行真实情况是什么）
        - AI 替代风险（哪些环节最先被替代）
        - 政策风险（监管收紧 / 资质变更 / 准入门槛抬升）
        - 个人健康风险（颈椎 / 视力 / 心理 / 慢病）
      不要回避——回避才会让学生进入岗位后感到被骗。

2. <意向岗位 2>
  （按 1.1 - 1.9 完全相同的结构展开，不要简化）

3. <意向岗位 3>（如有）
  （同上）
```

**写作纪律**：
- 调研某项无法落地时明确写「该项目前未查询到可靠数据，建议在 Boss 直聘 / 看准网 / 脉脉验证」——**不要编造**
- 每个意向岗位的展开篇幅大致相当，不要厚此薄彼
- 多个意向岗位的对比信息可以在本章末加一张「岗位对比一览表」（学历门槛 / 起薪 / 晋升节奏 / 风险水位 5 列），便于学生横向选择

### 第三章 城市与组织画像（v1.4 写作要点扩充）

**目的**：把学生未来 5-10 年要"生活其中"的具体环境讲清楚。城市决定生活成本和文化适配；组织决定每天和谁共事、什么节奏、走多远。每个子项至少 60-120 字。

#### 1. 意向城市画像（仅当学生填了具体城市；按 `research.md` 第 4 节调研结果展开）

```
1.1 <城市 1>

  1.1.1 主导产业与产业结构
        - 该城市排名前 3-5 的支柱产业
        - 与学生意向岗位 / 行业的匹配度（如杭州 vs 互联网 = 强匹配；郑州 vs 投行 = 弱匹配）
        - 城市定位标签（如「数字经济第一城」「西部金融中心」「制造业基地」）

  1.1.2 人才引进政策
        - 落户门槛（学历 / 社保 / 年龄要求）
        - 应届生补贴金额（具体到数字，注明政策有效期）
        - 住房支持（人才公寓 / 购房补贴 / 租房补贴）
        - 子女教育 / 配偶就业等附加政策
        - 政策稳定性判断（近 3 年是否大幅调整过）

  1.1.3 薪资与生活成本对照
        - 该城市平均月薪 + 中位数月薪
        - 学生意向岗位的应届起薪区间
        - 房租水平（合租 / 独居 / 一居室价位）
        - 通勤成本与时长（地铁 / 公交 / 通勤痛点）
        - 餐饮 / 娱乐 / 日常消费水位
        - 「学生意向薪资 - 房租 - 基本生活 = 可支配收入」估算

  1.1.4 城市发展规划
        - 十四五 / 十五五 规划中该城市的重点产业方向
        - 政府重点扶持的细分赛道
        - 未来 3-5 年是产业上升期还是相对滞缓
        - 是否在打造特定的「创新中心 / 产业集群」（与学生意向行业是否相关）

  1.1.5 文化与生活氛围
        - 城市性格（如成都 = 慢节奏休闲；深圳 = 快节奏冒险；杭州 = 互联网氛围）
        - 是否适合学生的性格画像（参考 Stage 4 答复）
        - 城市的"非工作时间"丰富度（自然 / 文化 / 社群）
        - 单身友好度 / 家庭友好度（结合学生人生红点方向判断）

  1.1.6 综合匹配度与建议
        - 这座城市 vs 学生意向岗位：1-10 分
        - 这座城市 vs 学生人生红点方向：1-10 分
        - 给学生的具体建议（推荐 / 中性 / 不推荐，理由各 1-2 句话）

1.2 <城市 2>（如有，按 1.1 完全相同的结构展开）
1.3 <城市 3>（如有，按 1.1 完全相同的结构展开）
```

如学生只填了大类（如「新一线」），不展开 1.1/1.2/1.3，改为「3 个推荐城市横向对比表」（推荐 3 个最契合 ta 意向岗位的城市，每个城市覆盖以上 6 个维度的核心要点）。

### 第四章 SWOT 与匹配度初判

**禁止使用任何通用 SWOT 条目**。每一条都必须直接引用学生信息 + 调研事实。

匹配度评分用 1-10 分量化每一个意向岗位，并给出文字理由。

### 第五章 三阶段目标（v1.2 引入 OKR 拆解）

**长期目标（毕业后 5-10 年）**：定位画像
**中期目标（毕业后 1-3 年）**：具体职位 + 公司类型 + 薪资带 + 城市
**短期目标（剩余学期内）**：可量化的关键交付物——**短期目标的时间锚点必须从 Stage 0 读到的真实当前学期开始**

每个目标必须 SMART：具体、可测、可达、相关、有时限。

**v1.2 增项：用 OKR 拆解中短期目标**

引用 `methodologies.md` 卡片 2 的 OKR 方法。中期目标和短期目标都用 **O + KR** 形式表达。

简短说明 OKR：

> 「OKR = Objectives + Key Results。O 是你想要什么（终点），KR 是去往终点必经的站点。完成所有 KR = 完成 O。KR 控制在 2-4 个、互相不重叠、以价值为导向（衡量效果，不只是衡量完成）。」

**中期目标 OKR 示范**（中期目标 = 毕业 1-3 年）：

```
O：以校招方式进入 <学生填的意向公司或行业代表性公司>，担任 <意向岗位>，过试用期并独立交付一个完整模块

KR1：本科最后两年内拿到至少 3 段对口实习（含 1 段大厂或目标公司），累计 8 个月以上
KR2：本科毕业时简历包含 2 个 GitHub Star ≥ 50 的项目 + 至少 1 篇深度技术博客
KR3：毕业前 6 个月内通过 5 家以上目标公司的技术面试，拿到 ≥ 3 个 Offer
KR4：入职后第一年内独立负责并上线 1 个模块，绩效 ≥ B+
```

**短期目标 OKR 示范**（短期目标 = 剩余学期）：会在第六章「分学期 OKR」中给出每学期的 O + KR。

### 第六章 分学期行动计划（v1.1 关键变化）

例 1：当前是 2026 年 5 月，学生填「大一下」→ 计划从「大一下学期最后 6 周 + 大一暑假」开始排

### 第七章 寒暑假专项行动计划（v1.1 新增 · 必含）

### 第九章 可迁移能力（综合能力）培养路线（v1.2 完整重写 · 必含）

**为什么独立成章**：可迁移能力——沟通、协作、领导力、自我激励、问题解决、批判性思维、学习能力——是越靠近真实职场越值钱、越难补的东西。专业技能可以临时补，但综合能力是要靠**重复参加学生组织 / 比赛 / 公益 / 实习 / 实训 / 项目**长期沉淀的。

**默认假设**：除非学生在 Stage 1 经历栏里明确列出了多段有深度的经历，否则**可迁移能力默认薄弱**，必须把本章列为高优先级补强项。

#### 1. 六大类 22 项可迁移能力概览

引用 `methodologies.md` 卡片 1 的完整分类表（情商 / 人际 / 管理 / 执行 / 分析理解 / 创造）展开。在计划书中只展示完整表格 + 一句话提醒：「你不必同时发展全部 22 项，关键是识别『你已掌握 + 你喜欢』的那几项作为优势能力，再针对意向岗位补齐 1-2 项必修能力。」

#### 2. 岗位 → 必备可迁移能力（针对意向岗位定制）

**核心动作**：根据学生填写的意向岗位，查 `methodologies.md` 卡片 1.3 的「岗位 → 必备可迁移能力」映射表，**列出该岗位最需要的 5 项可迁移能力**。

例（学生填「数据分析师」）：

> 数据分析师岗位最看重的 5 项可迁移能力，按优先级是：
> ① 发现问题（敏感识别数据异常 + 业务异常）
> ② 规划与研究（深度拆解问题，定方法）
> ③ 判断（多源信息筛选、得出可信结论）
> ④ 沟通协调（让业务方理解分析结果并采纳）
> ⑤ 学习能力（数据工具与方法论迭代极快）
>
> 这意味着你接下来的训练重心应当放在「在真实数据 / 真实问题中反复练习这 5 项能力」上，而不是平均用力。

学生意向岗位不在映射表时，模型应根据岗位调研（Stage 3.2）从 22 项中挑出最相关的 5 项。

#### 3. 「喜欢 + 掌握」自评矩阵（关键步骤）

让学生在拿到计划书后**自行填写**以下矩阵——这是最有洞察力的一步：**不是所有掌握的能力都值得发展，只有「喜欢 + 掌握」的才是真正的优势**。

填写说明：把 9.1 列出的 5 项岗位必备能力放在前 5 行，再补充学生在 Stage 1 经历中已经体现出的 3-5 项能力。

```
| 能力子项 | 掌握程度 (1-5) | 喜欢程度 (1-5) | 结论 |
| <岗位必备 1> | □ | □ | □ |
| <岗位必备 2> | □ | □ | □ |
| <岗位必备 3> | □ | □ | □ |
| <岗位必备 4> | □ | □ | □ |
| <岗位必备 5> | □ | □ | □ |
| <你已具备 1> | □ | □ | □ |
| <你已具备 2> | □ | □ | □ |
| ... | □ | □ | □ |
```

**结论判定规则**：
- 掌握 ≥ 4 且 喜欢 ≥ 4 → **优势能力**（重点开发、保持频率训练）
- 掌握 ≤ 3 且 喜欢 ≥ 4 → **潜力能力**（重点培养、需要刻意练习）
- 掌握 ≥ 4 且 喜欢 ≤ 2 → **不开发**（避免被消耗为「老好人」/「工具人」）
- 掌握 ≤ 2 且 喜欢 ≤ 2 → **跳过**（不必投入）

#### 4. 学生组织 / 协会 / 社团（培养：人际能力 + 管理能力）

- 建议加入 1-2 个组织（不贪多）
- 推荐类型：
  - 与意向岗位 / 行业相关的专业类社团（如计算机方向 → ACM 集训队 / 开源社团；金融方向 → 投资协会 / 模拟联合国）
  - 锻炼对人能力的综合类组织（如学生会、青协、辩论队、心理协会）
- 任职目标：大一干事 → 大二副部 → 大三部长 / 副主席的进阶路径
- 时间投入：每周 ≤ 8 小时，不影响学业

**沟通能力训练具体抓手**（嵌入 `methodologies.md` 卡片 4 SCQA 模型）：

> 在每次社团提案或汇报前，套一遍 SCQA：
> S（背景：当前情况是什么）→ C（冲突：出现了什么问题或差距）→ Q（提问：我们要解决的核心问题是什么）→ A（回答：我建议怎么做、需要哪些支持）
> 这套框架在大学社团 → 实习 → 工作面试 → 职场汇报全程通用。

#### 5. 学科竞赛（培养：分析理解能力 + 执行能力）

- 按岗位 / 行业匹配的赛事推荐 3-5 个（具体到比赛名，由意向岗位决定）
- 时间规划：哪个学期参加 / 哪个寒暑假准备（与第六、第七章联动）
- 目标分级：参与 / 校级奖 / 省级奖 / 国家级奖 / 国际级奖

#### 6. 公益 / 志愿服务（培养：情商能力 + 社会能力）

- 每学期至少 1 次有时长记录的志愿活动
- 推荐方向：
  - 与意向岗位有关（如想做教师 → 支教；想做产品 → 做老人 / 残障群体的用户调研类公益）
  - 一项与自己专业完全无关的（防止职业视角僵化）
- 累积时长建议：本科四年内 ≥ 80 小时

#### 7. 实习 / 实训（培养：执行能力 + 人际能力）

- 大学期间至少 2-3 段实习，时长累计 ≥ 6 个月
- 推荐时间分布（与第七章寒暑假联动）：
  - 大一暑假 → 校内实训 / 远程小项目实习
  - 大二暑假 → 中小公司或创业公司实习
  - 大三暑假 → 大厂 / 目标公司实习（决定秋招走向的关键）
- 每段实习的目标产出：1-2 个可写进简历的具体成果

#### 8. 项目（培养：创造能力 + 分析理解能力 + 执行能力）

- 大学期间累计 ≥ 3 个有可见产出的项目
- 推荐分类（与第八章专业技能章节联动）：
  - 基础工程类（大一-大二）：从 0 完成一个完整小项目
  - 方向特化类（大二-大三）：与意向岗位 / 技术栈直接相关的中等项目
  - 亮点项目（大三）：开源 / 比赛获奖 / 真实用户的差异化项目
- 项目托管要求：GitHub / 公开作品集 / 个人网站

#### 2. 备选方案（v1.4 重要逻辑修正）

**核心心法**：求职失利的备选方案**不是「直接转考公考研」**——那是把"找工作"和"读研深造"这两件本来要分别决策的事情粗暴混在一起。考公考研应当只在学生**主动选择**这条路径时才是 Plan A 或 Plan B，**不应作为"找不到工作的兜底"**。

求职失利的合理备选，应按以下优先级展开（适用于绝大多数学生）：

**Plan B：岗位梯队降级（同方向、降公司规模）**

- 目标公司从头部大厂 → 二线优质 / 中型公司 / 行业垂直公司 / 优质私企 / 创业公司
- 例：冲不进奇安信 / 安恒 → 试本地中型安全服务商、SaaS 公司的安全岗、甲方信息部
- 优点：**专业方向不丢、可迁移能力继续累积、2-3 年后跳槽窗口仍在**
- 操作要点：把简历对岗位重新打磨 1-2 版；放宽 base 期望 10-20%；把面试公司数提高到原计划的 1.5 倍

**Plan C：意向城市切换（同方向、换地理位置）**

- 当意向城市 HC 紧缩或匹配岗位极少时，按下面顺序考虑切换：
  1. **周边卫星城市**：如意向是杭州 → 嘉兴 / 绍兴；意向是厦门 → 福州 / 漳州
  2. **同档次有更多机会的城市**：如杭州互联网 HC 紧 → 成都 / 武汉；如厦门安全 HC 少 → 深圳 / 北京 / 上海
  3. **回家乡 / 户籍地的对应岗位**：在家乡找同方向的本地企业、政企信息化项目、本地科技园区
- 优点：**保住专业方向；生活成本可能更低；家乡资源 / 关系网可调动**
- 操作要点：提前调研当地的代表性公司清单；通过校友 / LinkedIn / BOSS 直聘补内推

**Plan D：利用应届生身份的时间窗口（不着急 · 继续提升）**

明确告诉学生一个被严重低估的事实：**在中国当前的就业政策下，毕业当年（多数省市为 7-8 月入职窗口前）找到工作仍然算应届生身份**——也就是说，6 月毕业典礼那天没拿到 Offer，并不意味着失去应届机会。

在毕业后的 1-6 个月内，学生可以选择：

- 系统性补技能（针对秋招暴露的能力缺口做专项训练）
- 参加**国科职规体系组织的就业冲刺班**——以小班制 / 项目演练 / Mock 面试 / 简历重打磨 / 内推对接为核心，针对秋招失利或还没找到合适岗位的应届生
- 利用毕业后的"间隔时段"完成一段对口实习（许多公司接受应届毕业生作为实习生过渡，3-6 个月后转正）
- 持续投递春招 / 夏招 / 提前批小规模招聘
- 关键：**保持每周 ≥ 25 小时的投入节奏 + 每月至少 5 次面试**，不要进入"摆烂等运气"的状态

**Plan E（仅当学生主动选择时）：考研深造 / 考公 / 留学**

这条路径**只在学生在大三上学期之前主动决定时才作为 Plan A 或 B 的并行选项**。如果学生 Stage 2 已经在"备选路径"里勾选了考研 / 考公 / 出国，则本计划书在前面章节就应该把它作为"主线 B"展开；不应在求职失利时临时启动——因为：

- 考研 / 考公 / 留学都需要至少 6-12 个月的系统准备，毕业前 3 个月才决定基本来不及
- 把"考研 / 考公"当成"找不到工作的避难所"，会让 ta 既不专心备考、也错过应届窗口期，两头落空
- 仅当学生本身价值观就偏向稳定 / 学术 / 体制内时，这条路径才真正适合

> ✅ 正确写法：「如果秋招失利，按 Plan B 降梯队 → Plan C 换城市 → Plan D 利用应届窗口（含国科就业冲刺班）三步走；只有当你本身就偏向稳定 / 体制内时，再启动 Plan E 考研考公。」

#### 5.1 强制要求（每次生成都必须满足）

1. **称呼**：用 Stage 1.0 收集的学生称呼直接呼名开头（如"亲爱的小林""嗨，Anna"）。如果学生跳过称呼，用"亲爱的你"作为开头。
2. **信件格式**：用"亲爱的 XX，..."开头，用署名"——国科职规体系 · 写于 [今天的日期]"或类似形式结尾，整段以"书信"形式呈现而非"段落"
3. **必须出现的四类内容**：
   - **深度针对性赞扬**（v1.4 加重）：必须从以下 6 类信息中挑出 **2-3 个具体闪光点**深度展开（每个闪光点至少 2-3 句话）：
     * 霍兰德代码体现的性格优势（如学生 RIA → 强调"动手 + 探究 + 创造"的稀缺组合）
     * MBTI 体现的认知方式（如学生 INFJ → 强调"内省 + 共情 + 远见"的难得特质）
     * 性格 / 习惯 / 抗压等自评中的强项
     * 心流场景透露的天赋方向（学生填的"完全投入"的事，往往最能预示天赋）
     * 自评优势中真诚但不被自己重视的部分
     * 兴趣爱好 / 特殊技能里隐藏的可迁移能力
   - **鼓励提前规划与勇敢思考**：明确肯定 ta 在当前时间点（结合 Stage 0 真实日期 + 学生年级）就愿意坐下来思考人生规划这件事本身的价值
   - **预祝卓越职场 + 美好人生**：不要用「祝你前程似锦」这种通用句式；要把祝福**具象到 ta 的目标岗位、目标城市、人生红点方向、当下心境**上
   - **行动召唤**：信末给 ta 一个具体的下一步（"合上这份文档后，请先做的一件小事是…"），让信不只是煽情而是有抓手
4. **长度**：v1.4 由 200-350 字 **提升到 300-500 字**——既然改成"信"，就要有信的份量
5. **情绪**：感情充沛、直入内心，让学生感受到"这份报告是真的为我写的"。允许出现情绪化用词（"我为你高兴""我替你抱过这份选择"），但不允许油腻或夸张
6. **署名**：信末用以下三选一的落款（每次轮换）：
   - "——国科职规体系 · 写于 <今天日期>"
   - "——你的 AI 职业规划伙伴 · <今天日期>"
   - "——国科职规 AI 规划师 · <今天日期>"

#### 5.2 反重复随机化机制（核心创新）

**问题**：如果每次都用同一套模板写结尾，学生重复测试 / 同班同学互看时会立即识破——这会严重损害计划书的公信力。

**解决方案**：把结尾段拆成 5 个「写作维度」，每次生成时模型必须**随机选择不同组合 + 不同句式**展开。下面给出每个维度的多种「角度库」，但**不是模板**——模型应当从这些角度获得启发，然后用自己的语言重新组织。

##### 维度 A：开场方式（必选 1 种，但每次换）

A1. **直接呼名 + 一句情境化感慨**（如「张三，写到这里，我看着你填的『大一下，绩点 3.42，加入了学生会』这几个字，突然想停下来跟你说几句」）
A2. **从学生填写的某句原话切入**（如「你在『当下情绪』那一栏填了『焦虑，怕来不及』。这五个字让我想停下职业规划的语气，先跟你聊点别的」）
A3. **从一个具体的画面切入**（如「想象一下五年后的某个工作日傍晚，你刚走出 <学生意向公司> 的办公楼。那时候的你回头看大学时代，最感谢哪一年的自己？」）
A4. **从一个时间锚点切入**（如「今天是 2026 年 5 月 22 日。你大一下学期的期末考还有 6 周。这份计划书可能不会改变你的期末成绩，但希望它能改变你看待这 6 周的方式」）
A5. **反问 / 设问**（如「为什么我希望你认真读完这份计划书？因为大学最珍贵的事情，从来都不是『被规划好』，而是『学会规划自己』」）
A6. **直接表达「被打动」的瞬间**（如「在你回答完那 15 个问题之后，我心里其实只有一句话想说：你比自己以为的要清醒得多」）

##### 维度 B：针对性赞扬（必选 2-3 种，每次抓不同细节，v1.4 加重至 2-3 项深度展开）

B1. 赞扬 ta **填写时的诚实与坦率**（特别适合学生填了"挂科 / 迷茫 / 倦怠"等"不光彩"内容的情况）
B2. 赞扬 ta **某段经历背后的品质**（如学生填了"做过 2 年志愿者 = 共情力"、"参加 ACM 没拿奖 = 不怕失败"、"绩点 3.9 = 自律"）
B3. 赞扬 ta **目标的明确度 / 模糊度都好**（明确目标 → 赞稀缺；模糊目标 → 赞坦然不装懂）
B4. 赞扬 ta **某个看似不相关的细节体现的潜力**（如填了"喜欢摄影"→ 暗示审美能力；填了"经常熬夜帮室友改简历"→ 暗示服务他人的天赋）
B5. 赞扬 ta **当下选择「提前思考」的决定本身**（特别是大一 / 大二的学生，要明确指出"大三才想这些的人比比皆是，你比他们提前了 1-2 年"）
B6. 赞扬 ta **填写过程中的 self-awareness**（如清楚知道自己的短板、不掩饰情绪状态）
B7. **(v1.4 新增) 赞扬 ta 的霍兰德代码所体现的优势组合**（如学生 RIA = 既能动手又愿钻研还有审美，是技术 + 创造类岗位的稀缺人才；如学生 SEC = 既能社交又能领导又能守规则，适合做团队管理者）——必须挑学生代码中**最具张力的两个字母组合**讲，不要把三个字母平均铺开
B8. **(v1.4 新增) 赞扬 ta 的 MBTI 所体现的独特性**（如 INFJ 是 16 型里占比仅 1-2% 的稀有型，强调 ta 的内省 + 共情 + 远见三件套；如 ENTP 强调 ta 的快速整合 + 辩论 + 创造力的天然组合）——务必结合 MBTI 对应的真实价值场景，不要堆术语
B9. **(v1.4 新增) 从学生「心流场景」/「兴趣爱好」/「特殊技能」中挑出 1 个看似"非主流"的细节深度发挥**（这一条往往是整封信里最打动学生的部分——因为这是学生自己都没意识到的、被一个"陌生人"看见的优势）

##### 维度 C：对「提前规划与勇敢思考」的肯定（必选 1 种）

C1. 把这件事放在 **同龄人对比的视角**：大多数同学在大三 / 大四焦头烂额时才想这些
C2. 放在 **时间复利的视角**：你今天每多想 1 小时，未来都在替你赚
C3. 放在 **自我认知的视角**：能坐下来回答完这 15 个问题 = 已经在做大多数同龄人都不愿做的事
C4. 放在 **「不确定性」的视角**：愿意在不确定时下场思考，而不是等"想清楚再行动"，这本身就是稀缺品质
C5. 放在 **「敢直面终局」的视角**：很多人这辈子都不敢认真问自己想要什么，而你今天问了

##### 维度 D：祝愿的具象化（必选 1-2 种）

D1. 把祝愿绑定到学生的 **意向岗位**（如「希望 5 年后看到你在 <字节后端组 / 浙江省委 / 央视新闻部> 推动一些事情」）
D2. 把祝愿绑定到学生的 **意向城市**（如「希望你的 < 2030 年的杭州> 是你长出根的地方而不只是飘过去的一站」）
D3. 把祝愿绑定到学生的 **人生红点方向**（如学生倾向「作品型」→ 「希望你将来真的能做出一些会留下来的东西」）
D4. 祝愿 ta **不被路上的迷茫吓到**（特别适合当下情绪是迷茫 / 焦虑的学生）
D5. 祝愿 ta **找到能让自己长期发光的事**（红点方向不明确时用）
D6. 祝愿 ta **既能成事也能成人**（强调职业成就之外的「成为什么样的人」）
D7. **不用「祝」字、不用「前程似锦」**——可以改用「我相信」「我期待」「我希望某天能听到」等更个人化的句式

##### 维度 E：收尾方式（必选 1 种）

E1. **「这份计划书是活的」**：明确告诉 ta，每学期可以回来更新版本
E2. **一句给 ta 拿走的话**（一句箴言式的总结，引自学生自己填的话或对话中提炼）
E3. **指向一个具体的下一步**（如「合上这份文档之后，请做的第一件事是 <最小可行的具体动作>」）
E4. **「我们再见」的语气**（让 ta 知道这不是一次性服务，下次还可以来）
E5. **回到开头那个画面 / 那个问题**（首尾呼应，形成完整感）

#### 5.3 反重复硬约束（执行时必须遵守）

每次生成结尾信，模型必须：

1. 用 Stage 0 读到的当前时间戳作为「随机种子」，从上述 5 个维度的「角度库」中选出不同的组合（A 选 1、**B 选 2-3（v1.4 加重）**、C 选 1、D 选 1-2、E 选 1）
2. **绝不**复制本文件中给出的任何示例原句——它们只是激发灵感的种子，不是模板
3. 至少包含 **3 个具体到只属于这位学生的细节**（v1.4 从 2 个增加到 3 个）—— 例如：具体的姓名 / 经历 / 数字 / 情绪状态 / MBTI 字母 / 霍兰德字母 / 一句原话 / 一处心流场景 / 一个兴趣
4. **必须用书信格式**：以"亲爱的 XX，..."开头，以"——<署名> · <日期>"结尾
5. **禁止使用以下烂大街句式**：
   - 「祝你前程似锦，万事如意」
   - 「相信通过你的努力一定能实现梦想」
   - 「未来可期」
   - 「加油，你是最棒的」
   - 「人生的道路上充满挑战」
   - 「相信你能行」
   - 任何不含具体细节的通用语
6. 即使同一个学生重复来请求生成计划书，结尾信也必须**显著不同**——可以重新挑维度、重新挑细节、重新找切入点

## 第 8 节：附录 · 方法论速查卡（v1.2 新增）

在计划书末尾追加一节「方法论速查卡」，便于学生离开计划书后随时翻阅。建议采用下面的紧凑表格形式（不要展开成大段文字）。

### 8.1 OKR 撰写四原则
- MECE：关键结果不重复不遗漏
- 数量 2-4 个，更少更聚焦
- 价值导向（衡量效果，不只是衡量完成）
- 每个 KR 有时间锚点

### 8.2 时间矩阵四象限
- 使用时间（重要紧急）40-50%
- 投资时间（重要不紧急）30-40% ← 最容易被忽视
- 浪费时间（不重要紧急）≤ 10%
- 闲耗时间（不重要不紧急）≤ 15%

### 8.3 SCQA 表达框架
- S Situation 背景
- C Complication 冲突
- Q Question 提问
- A Answer 回答

### 8.4 可迁移能力六大类
- 情商 / 人际 / 管理 / 执行 / 分析理解 / 创造
- 关键洞察：「掌握 + 喜欢」的能力 = 真正的优势能力

### 8.5 人生红点九类型
- 现实主义结果导向：赚钱型、出名型
- 现实主义过程导向：生活型、体验型、过程型
- 理想主义结果导向：作品型、成就型
- 理想主义过程导向：内心型、高手型
