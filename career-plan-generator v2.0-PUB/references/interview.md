# 问询问题库 (Interview Bank) · v1.4

本文件为 SKILL.md 中 Stage 1 / 2 / 4 / 5 的具体提问文本与选项库。执行技能时请直接套用或在此基础上做轻量改写。

**v1.3 关键变化**：
- 学期问题只问「上学期 / 下学期」，**不预设年级**，年级由学生自述（让对话不显得"AI 在猜"）
- 意向岗位改为**完全开放填写**，不给固定选项
- **学生活动经历**单独作为一题问询，不再塞进「其他补充」
- **自我认知部分加入 MBTI 选填项**
- **拆分复合问题为多轮单一问题**，让学生有"被深度咨询"的体感

## 第 1 节：Stage 1 基础信息收集（拆分为多轮）

### 1.0 称呼（v1.4 前置 · 必做第一题）

> 在我们正式开始之前，先问一句：你希望我怎么称呼你？
>
> 可以是你的真实姓名、昵称、英文名、网名，甚至是你想被叫的样子（比如「小李」「Anna」「老张」）。这个称呼会出现在计划书的封面以及结尾的那封信里。
>
> 如果不想透露，可以写「跳过」——我会全程用「你」来称呼你，但少了一点专属感。

**重要**：拿到称呼后，Claude 在后续所有对话中**至少每 3-5 轮就自然地用一次这个称呼**（如「小林，下一题…」「Anna，再帮我确认下…」），让学生在整个 30 分钟咨询过程里始终感受到「这是一对一的对话」，而不是「在填表」。

### 1.3 当前年级（开放式 · v1.3 新做法）

> 你目前是大几 / 研几？请简短告诉我（例如：「大二」「研一」「大专三年级」）。

学生自述年级。模型把「学制 + 学期 + 学生自述年级 + Stage 0 当前日期」组合，推算出真实的成长阶段，作为后续时间锚点。

例：
- 学制本科 + 学期下学期 + 学生自述「大二」+ 当前 2026 年 5 月 → 推算「大二下学期最后阶段，距离大三上还有 ~3 个月」
- 学制硕士 + 学期上学期 + 学生自述「研一」+ 当前 2026 年 10 月 → 推算「研一上学期，距离秋招还有约 1 年」

### 1.9 学生活动经历（v1.3 新增 · 单独一轮 · 重点询问）

> 学生活动经历是计划书里非常重要的一部分——它直接决定了你**可迁移能力**的现状判断，也是简历里最常被忽视、却最区分人的部分。请尽量详细地告诉我以下信息：
>
> **A. 学生组织 / 社团 / 协会**
> - 你加入过哪些组织？（如学生会、青年志愿者协会、专业类社团、ACM 集训队、辩论队、文艺社团等）
> - 担任过的职务（干事 / 副部 / 部长 / 主席等）？
> - 任职时长？
> - 你在里面主要做了什么、负责什么、产出过什么？
>
> **B. 学科竞赛 / 比赛**
> - 参加过哪些比赛？（如蓝桥杯、ACM、数学建模、互联网+、挑战杯、英语竞赛、专业类比赛等）
> - 获奖等级（参与 / 校级 / 省级 / 国家级 / 国际级）？
> - 你在比赛中担任的角色？
>
> **C. 志愿服务 / 公益**
> - 你做过哪些志愿服务？（如支教、社区服务、大型赛会志愿者、专项公益等）
> - 总累计时长大致多少？
> - 印象最深的一次是？
>
> **D. 兼职 / 实习 / 实训**
> - 做过哪些兼职 / 实习？
> - 公司或机构名（不便透露写「某互联网公司」即可）+ 岗位 + 时长 + 主要工作内容？

**重要提醒（写给执行技能的 Claude）**：
- 这一题是诊断「可迁移能力薄弱与否」的关键依据
- 如果学生这一题回答得很简短（如「没参加过什么社团」「没获过奖」），请**不要回避或粉饰**，在后续生成计划书时直接列为高优先级补强项
- 如果学生有丰富经历，请把每一条都映射到第九章「可迁移能力培养路线」的对应能力类型上

### 1.10 项目经验（开放式 · 单独一轮）

> 项目经验在你的简历里同样重要，请告诉我：
>
> - 你做过的项目名 / 主题是？
> - 项目内容简介（一两句话）？
> - 你在项目里的角色（独立完成 / 团队合作 / 担任组长等）？
> - 关键产出（代码 / 论文 / 报告 / 上线产品等）？
> - 是否有公开链接（GitHub / 个人网站 / 公开发表的论文）？
>
> 如果还没有可以写「无」，但请告诉我是否有过想做但没做的项目想法。

### 1.11 其他补充（开放式 · 真正用于"补充"）

> 还有什么你认为重要、但前面没问到的背景信息？例如：
> - 地域限制 / 是否愿意离家
> - 家庭背景对职业选择的影响
> - 健康因素
> - 特殊技能（绘画 / 乐器 / 摄影 / 写作 / 主持 / 语言天赋等）
> - 你希望我特别关注的某个困扰
>
> 没有也可以直接写「没有」。

## 第 2 节：Stage 2 目标信息收集（v1.3 拆分为多轮 + 开放式）

### 2.1 意向岗位（开放式 · v1.3 完全开放）

> 你最想从事什么样的工作？请按自己的话写出 1-3 个**意向岗位方向**，按优先级排序。
>
> 这可以是：
> - 一个明确的岗位（如「字节跳动后端工程师」「中学语文老师」「某大型律所知识产权律师」）
> - 一个泛指方向（如「互联网行业的算法相关岗位」「金融机构的合规相关工作」「考公进事业单位做行政」「自媒体内容创作」「自由职业 / 创业」）
> - 一个朦胧但有方向感的描述（如「想做和文字 / 写作相关的工作，但不确定具体岗位」「想找一份能跟家人离得近的稳定工作」）
>
> 写不出具体岗位也没关系——给我 2-3 个朦胧方向，我们会调研完之后帮你聚焦。

**禁止行为（写给执行技能的 Claude）**：
- **不要**给出「互联网 / 金融 / 国企 / 考公」之类的有限选项让学生选；岗位是非常个人化的，必须由学生自己说
- 如果学生给出的描述模糊，可以追问一句：「能不能再多说一句？比如『内容创作』是想做短视频 UP 主、记者、文案策划，还是公众号写作？」——但是只追问，不要给选项

### 2.3 具体意向城市（开放式 · 可选）

>
> 我会调研这些城市的人才政策、平均薪酬、城市发展规划，让规划更贴合你的目的地。
>
> 没有具体偏好可以写「跳过」。

### 2.4 薪资期望（开放式）

> 请给我两个数字：
> 1. 应届起薪你希望达到多少？（月薪税前，单位：元/月）
> 2. 工作 3-5 年后希望年薪达到多少？（单位：万元/年）
>
> 不确定可以填「未知」，或者给一个区间范围。

### 2.5 意向公司 / 组织（开放式 · 可选 · 单独一轮）

> 你有没有 1-3 家心仪的具体公司或组织？可以是大厂、国企、事业单位、外企、研究所、初创公司、NGO，甚至某位老师 / 博主推荐你的某家公司。
>
> 我会调研这些组织的业务地位、近况、招聘风格，让规划能直击目标。
>
> 没有具体目标也可以写「暂时没有」——我会按你的意向岗位推荐行业内代表性组织。

### 2.6 备选路径（AskUserQuestion · 多选）

> 在直接就业之外，你是否也在考虑其他出路？（可多选）

| label | description |
| --- | --- |

## 第 5 节：留白处理规则

学生有权跳过任何一项。但留白会影响某些章节的精确度：

| 留白项 | 影响 | 处理方式 |
| --- | --- | --- |
| 绩点 / 排名 | SWOT 优势 / 劣势章节 | 让学生给出「top 10% / 30% / 中游 / 下游」相对位置即可 |
| 实习经历 | 简历优势章节 | 标注「待补充」，不编造 |
| 学生活动经历薄弱 | 可迁移能力章节 | 不回避——明确列为补强项 |
| 性格 / 情绪 | 匹配度诊断、温度感章节 | 用「未填写，建议做正式测评后回填」一句带过 |
| MBTI | 自我认知 + 匹配度章节 | 跳过 MBTI 分析，但保留其他认知信息 |
| 霍兰德代码 | 第十三章匹配分析章节 | 替换为「建议你完成 SDS 测试后再回看本章节」 |
| 意向城市 | 城市调研章节 | 跳过具体调研，仅按地点诉求大类做大类分析 |
| 意向公司 | 组织调研章节 | 跳过具体调研，自动推荐 3-5 个行业内代表性组织 |
| 薪资期望 | 行业薪资对照章节 | 跳过对照，仅列岗位薪资数据 |
| 学校名 | 不影响 | 用「你的院校层次 + 专业」代替 |

无论留白多少，最终交付的计划书必须满足以下最低必需信息：
- 学制
- 学期 + 自述年级
- 院校层次
- 专业
- 意向岗位（至少 1 个，可朦胧）

缺这五项任何一项 → 提示学生「这五项是最低必需信息，没有这些无法生成定制版」。

## 第 6 节：问询节奏建议（v1.3 新增 · 让对话有"深度咨询感"）

执行 Stage 1-5 时，**不要**把所有问题堆在一条消息里发给学生。建议节奏：

1. Stage 1 拆为 12 轮单独问询（**称呼**、学制、学期、年级、院校、学校专业、学业、语言证书、行业证书、**学生活动**、项目、其他补充）
2. Stage 2 拆为 6 轮（意向岗位、地点大类、具体城市、薪资、意向公司、备选路径）
3. Stage 3 调研（不询问，自动执行）+ 中场汇报 + **落差补充确认**
4. Stage 4 拆为 13 轮（性格、抗压、团队、自律、行动模式、持续力、优势短板、心流、心境、执行力、困扰、MBTI、霍兰德）
5. Stage 5 拆为 2 轮（风格、节奏；署名已在 1.0 收集）

**问询过程中**：
- 学生回答简短时，可以"延展一句"追问（如学生只填了"加入了学生会"→ 追问"具体在哪个部门？担任什么职务？做了多久？")，但不超过 2 轮追问
- 学生明显疲惫 / 想加速时（如"快点直接生成吧"），允许跳过中间几轮，但 Stage 3 调研 + 落差补充确认 + Stage 4 心境 + Stage 5 不能省

**目的**：让学生感受到的是"被一位职业规划师认真访谈"，而不是"被 AI 塞了一张表"。
