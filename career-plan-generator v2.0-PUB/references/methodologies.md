# 方法论库 (Methodology Cards) · v1.2

本文件存放四套大学生职业规划与日常自我管理所需的核心方法论。`plan_template.md` 在写到对应章节时**应当**引用这些卡片，让学生在拿到计划书时同时拿到一套可终身使用的工具。

收录：

1. 可迁移能力六大类详解（用于第九章 + 7-D 替代岗位推荐）
2. OKR 目标拆解方法（用于第五章 + 第六章 + 寒暑假规划）
3. 时间管理矩阵（用于第十二章评估机制 + 寒暑假规划）
4. 沟通管理 SCQA 框架（用于可迁移能力 9.1 沟通能力培养）

每张卡片都给出：核心概念 → 学生场景化用法 → 嵌入哪一章。

### 1.2 「喜欢 / 不喜欢」分类法（关键洞察）

> 把你掌握的能力按「喜欢 / 不喜欢」分类。
> **不是所有掌握的能力都值得发展**——有的人有共情能力但讨厌当老好人；有的人擅长应酬但厌倦人情往来。
> **「喜欢 + 掌握」的能力才是有潜力的优势能力**。

学生自评矩阵建议表（在第九章使用）：

| 能力子项 | 掌握程度 (1-5) | 喜欢程度 (1-5) | 结论 |
| --- | :---: | :---: | --- |
| 沟通协调 | | | 优势 / 潜力 / 不开发 |
| 自我激励 | | | |
| 团队合作 | | | |
| 组织统筹 | | | |
| 问题解决 | | | |
| 学习能力 | | | |
| ... | | | |

**结论判断规则**：
- 掌握 ≥ 4 且 喜欢 ≥ 4 → **优势能力**（重点开发）
- 掌握 ≤ 3 且 喜欢 ≥ 4 → **潜力能力**（重点培养）
- 掌握 ≥ 4 且 喜欢 ≤ 2 → **不开发**（不必投入，避免陷入"老好人"困境）
- 掌握 ≤ 2 且 喜欢 ≤ 2 → **跳过**

## 卡片 2：OKR 目标拆解方法

> 出处：《目标管理 OKR》

### 2.1 核心概念

**OKR = Objectives + Key Results**

| 概念 | 含义 |
| --- | --- |
| O（Objective） | 我想要什么（方向 / 终点） |
| KR（Key Result） | 如何衡量是否完成？必经的站点是什么？ |

**O 与 KR 的关系**：O 是目的地，KR 是去往目的地必须经过的站点。完成所有 KR = 完成 O。

### 2.2 撰写关键结果的四原则

```
1. MECE：关键结果之间不重复、不遗漏（来自麦肯锡）
2. 数量：控制在 2-4 个最佳（更少 → 更聚焦）
3. 价值导向：衡量「效果」而不是「完成任务」
   例：×「发布新版本」 → √「发布新版本，将口碑从 X 提到 Y」
4. 时间锚定：每个 KR 都要有可衡量的时间点
```

### 2.3 假设分析法（找到关键结果的三步）

```
第一步：明确现状与目标的差值（如：销售 3000 万 vs 目标 5000 万 = 差 2000 万）
第二步：假设差值产生的原因（销售渠道不足？大客户减少？人员问题？）
第三步：多方求证（同事讨论 / 资深前辈意见 / 数据验证），明确可执行假设
```

### 2.4 学生场景化案例（用在计划书第六章）

**示例 1：大一下学期个人 OKR**

```
O：在大一下学期结束前，建立扎实的编程基础并完成第一个开源项目

KR1（学业）：数据结构课程期末 ≥ 92 分，并完成所有课后实验
KR2（技能）：LeetCode 累计 AC ≥ 150 题，其中 Medium ≥ 30 题
KR3（项目）：在 GitHub 提交完整的「个人博客系统」，commit ≥ 50 次，README 与单元测试齐全
KR4（可迁移）：加入校 ACM 集训队，参加每周至少 2 次集训
```

**示例 2：大三暑期 OKR**

```
O：拿到至少一家一线大厂暑期实习并争取转正

KR1：3 月底前完成至少 5 家大厂暑期实习投递与简历优化
KR2：4 月底前通过至少 3 家公司的技术面试
KR3：6 月底前 mentor 给出口头转正意向
KR4：实习期间独立负责并上线 1 个模块，写完 3 篇技术博客
```

### 2.5 嵌入位置

- 第五章「三阶段目标」—— 引导学生用 O + KR 形式重写自己的目标
- 第六章「分学期行动计划」—— 每个学期目标用 OKR 拆解（O + 2-4 个 KR）
- 第七章「寒暑假专项行动」—— 每个寒暑假用一份小型 OKR 收尾

### 2.6 OKR 与 KPI 的区别（一句话）

> OKR 是主动做事，KPI 是被动执行。学生时代应当主动培养 OKR 的思维方式。

## 卡片 3：时间管理矩阵

> 出处：《时间管理》

### 3.1 浪费时间的三大元凶

```
1. 不了解时间（不知道自己一天有多少可用时间、最高效时段在何时）
2. 琐事优先（眼见什么做什么；大脑喜欢简单、即时、熟悉的事 → 鸵鸟心态）
3. 贪心 vs 时间不足（既要质量又要数量、什么都想要 → 越焦虑越低效）
```

### 3.2 时间管理矩阵（四象限 + 学生类比）

```
                  紧急              不紧急
重要      ┌─────────────┬─────────────┐
          │  使用时间      │  投资时间      │
          │  「合理消费」  │  「理财增值」  │
          │ 日常课业、     │ 学新技能、     │
          │ 期末复习、     │ 锻炼身体、     │
          │ 重要 ddl       │ 长期项目、     │
          │                │ 经营关系       │
不重要    ├─────────────┼─────────────┤
          │  浪费时间      │  闲耗时间      │
          │  「过度花费」  │  「财产贬值」  │
          │ 别人塞过来的   │ 刷短视频、     │
          │ 杂事、         │ 打游戏、       │
          │ 不必要的会议、 │ 漫无目的的     │
          │ 帮跑腿         │ 社交           │
          └─────────────┴─────────────┘
```

### 3.3 理想比例（学生版）

```
使用时间：40-50%
投资时间：30-40%   ← 大学生最容易被忽视的板块，必须主动保障
浪费时间：≤ 10%
闲耗时间：≤ 15%
```

**关键洞察**：如果你的投资时间每天比同学多 2 小时，一个月 = 60 小时，一年 = 700+ 小时——相当于多读 30 本书 / 多完成 2 个项目 / 多刷 1000 道算法题。

### 3.4 黄金时间与时间黑洞（学生场景）

- **黄金时间**：一天中精力最充沛的时段。一般大学生有两段：早晨 8-11 点、晚上 8-11 点。**核心任务（专业课预习 / 论文 / 项目 / 算法题）必须放在黄金时间。**
- **时间黑洞**：在不知不觉中吞噬时间的习惯。学生常见黑洞：刷短视频、淘宝、看综艺、过度社交、躺床上想事情。

### 3.5 优化时间矩阵的三步

```
1. 利用时间清单分析自己一周的时间使用情况（建议：连续记录 7 天）
2. 缩减或转化浪费时间与闲耗时间，转换成投资时间
3. 利用投资时间，让使用时间变得更高效
```

### 3.6 嵌入位置

- 第十二章「评估机制与定期复盘」—— 给学生一份「时间管理矩阵自检表」
- 第七章「寒暑假专项行动」—— 假期更需要规划好「使用 / 投资 / 浪费 / 闲耗」分配
- 第六章「分学期行动计划」每学期 KPI 中至少包含一项「保留每天 2 小时投资时间」

## 卡片 4：沟通管理 · SCQA 框架

> 出处：《沟通管理》

### 4.1 沟通的本质（一句话）

> 沟通的本质是**信息的双向传递**；关键不在于「你说了什么」，而在于「对方听懂了多少 + 是否给出反馈」。

### 4.2 信息漏斗：六个环节都有损耗

```
原始信息 → 加工 → 传递 → 接收 → 理解 → 反馈
        ↓        ↓       ↓       ↓       ↓
      会损耗   会损耗   会损耗   会损耗   会损耗
```

### 4.3 沟通不畅的四种坏心态（必须避免）

```
1. 忽视信息损耗：默认对方应该懂我的意思
2. 刻板印象：他就是这样的人，懒得说
3. 过度自尊：我凭什么要迁就你
4. 道德制高点：我是对的，大家都得听我的
```

### 4.4 SCQA 表达模型

任何一次结构化表达（口头汇报、面试自我介绍、给老板的邮件）都可以套这个框架：

```
S (Situation 背景)：先陈述事件发生的背景，让对方代入
C (Complication 冲突)：让对方意识到问题存在
Q (Question 提问)：明确问题，引发共同思考
A (Answer 回答)：提出可能性方案，共同探讨
```

**学生场景示例：面试中介绍一个项目**

```
S：大二下学期我所在的 ACM 集训队接到了承办校内程序设计大赛的任务
C：但我们只有 2 周时间筹备，且过去三年的题目库已被大量学生刷过
Q：如何在 2 周内组织一场对所有人公平的、新题占比 ≥ 80% 的比赛？
A：我牵头制作了一套「按知识点抽样 + 题面变形 + 数据集重新生成」的出题流程，
   最终发布了 12 道全新题，竞赛参与人数比上届提升了 60%
```

### 4.5 沟通前 / 中 / 后注意事项

| 阶段 | 核心动作 |
| --- | --- |
| 前 | 明确目的；了解接收者背景；预判可能异议 |
| 中 | 结构化表达；倾听 + 提问；换位思考 |
| 后 | 关注对方反馈；确认共识；必要时落地为文字 |

### 4.6 嵌入位置

- 第九章 9.1 沟通协调能力 —— 引用 SCQA + 双向沟通模型作为训练抓手
- 第六章 KPI —— 每学期至少完成 1 次 5 分钟以上的公开表达（社团分享、课程汇报、面试 Mock）
- 第 7-B 心理准备 —— 提醒学生进入职场后沟通能力比技术能力更影响晋升速度

## 第 5 节：如何在生成报告时使用本文件
