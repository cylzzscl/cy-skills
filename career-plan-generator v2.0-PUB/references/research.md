# 四维真实调研指引 (Job · Industry · City · Organization Research Playbook) · v1.1

本文件是 SKILL.md 中 Stage 3 的执行手册。Stage 3 是把「通用建议」升级为「定制化建议」的核心环节——没有调研，本技能等于失效。

v1.1 把调研从原来的「岗位 + 行业」两维扩展为「行业 + 岗位 + 城市 + 组织」四维，并完全对齐《2026 职业规划工坊（第三 part）》的调研清单。

---

## 第 1 节：为什么必须做这一步（也为什么是四维）

WWRH 框架里有一句话：「**必须调研**：外面世界怎么样、岗位 / 行业 / 考试真实规则」。

学生填写的「意向岗位 / 城市 / 公司」可能是从家长、师兄、社交媒体听来的模糊认知。如果模型直接拿这些名字套用自己的训练知识，几乎一定会给出过时或失真的信息——尤其是薪资、招聘要求、行业前景、城市政策、公司近况这些每年都在变。

调研的根本目的不是「证明模型懂这个岗位」，而是产出学生本人能直接引用的、来自 2024-2026 年最新一手数据的**事实**。

四个维度缺一不可：
- **行业**——决定你处在上升期还是夕阳行业（找对赛道）
- **岗位**——决定你具体每天做什么、需要什么硬技能（找对车）
- **城市**——决定你的生活成本、薪资水位、人才政策、产业匹配（找对路）
- **组织**——决定你的直接环境、文化匹配、晋升天花板（找对车队）

## 第 2 节：行业调研维度

参照第三 part「行业信息」清单，每个意向岗位所属行业都要覆盖以下三个方面。

### 2.1 国家宏观经济政策

- 国家是否大力提倡发展该行业？（核查十四五 / 十五五规划文本）
- 该行业是否出现在年度《政府工作报告》中？
- 是否有明确的产业扶持政策（专项基金、税收减免、人才补贴）？

**搜索关键词**：

```
<行业> 十四五 规划
<行业> 十五五 规划
<行业> 政府工作报告 2025 2026
<行业> 产业政策 国务院
<行业> 国家 战略性产业
```

### 2.2 行业现状与发展趋势

- 当前处在哪个阶段：**发展初期 / 成长期 / 成熟期 / 衰退期**？
- 不同阶段意味着不同特点：
  - 发展初期：前景开阔，但风险较高
  - 成长期：机会较多，节奏很快
  - 成熟期：机会减少，竞争增加，但福利相对完善
  - 衰退期：不建议进入（夕阳行业）

**搜索关键词**：

```
<行业> 发展阶段 周期
<行业> 市场规模 2025
<行业> 现状 趋势 2026
<行业> 红利 是否消退
<行业> 衰退 转型
```

### 2.3 行业市场信息

- 市场规模（产值 / 用户数 / 公司数）
- 主要公司及其市场份额
- 主要业务类型与商业模式
- 当前热点细分（如教育行业的「编程教育」「素质教育」）

**搜索关键词**：

```
<行业> 市场规模 报告
<行业> 头部公司 排名
<行业> 商业模式
<行业> 主要业务 细分
艾瑞 / 易观 / IDC <行业> 报告
```

## 第 3 节：岗位调研维度

参照第三 part「职业（岗位）信息」清单，每个意向岗位按下面 6 大块展开。这是本技能最核心的调研模块。

### 3.1 工作性质

- 主要职责
- 产生的产品 / 提供的服务
- 内部专业细分（同一岗位下的不同方向）
- 使用的设备、工具、机器、软件

**搜索关键词**：

```
<岗位名> 职责 JD
<岗位名> 主要工作内容
<岗位名> 一天 知乎
<岗位名> 工作流程
<岗位名> 工具 软件
```

### 3.2 教育水平

- 学历底线（专科 / 本科 / 硕士 / 博士）
- 偏好专业
- 进入该行业所需的工作 / 实习经验

**搜索关键词**：

```
<岗位名> 学历要求
<岗位名> 应届生 学历
<岗位名> 专业 限制
<岗位名> 校招 要求
```

### 3.3 职业要求（**专业能力 + 可迁移能力**）

参照第三 part 强调的"可迁移能力"概念，调研时必须区分两类：

- **专业能力**：硬技能（具体工具、框架、方法论、行业 know-how）
- **可迁移能力**：沟通、协作、领导力、表达、项目管理、抗压、学习能力、问题解决等综合素养
- 体力 / 身体要求（举重、长时间站立、视力、听力、色盲、攀爬等）
- 个人兴趣（与数据 / 人 / 事物打交道）
- 特殊品质或气质标准（如打字速度、外形、口音）
- 法律 / 资质要求（执照、证书、外语等）

**搜索关键词**：

```
<岗位名> 必备技能
<岗位名> 软技能 沟通 领导力
<岗位名> 可迁移能力
<岗位名> 体能 要求
<岗位名> 资格证 必须
<岗位名> 性格 气质 偏好
```

### 3.4 薪资福利

- 起薪 / 平均工资 / 最高薪酬
- 通常提供的福利（退休金、保险、假期、病假、年终奖）

**搜索关键词**：

```
<岗位名> 应届 薪资 <城市>
<岗位名> 起薪 校招 2025 2026
<岗位名> 薪资 区间 三年 五年
看准网 <岗位名> 薪资
职友集 <岗位名>
<岗位名> 年终奖 福利
```

### 3.5 工作条件

- 物质条件与安全（办公室 / 工厂 / 户外 / 噪音 / 温度）
- 工作时间（小时 / 白班夜班 / 加班 / 季节性）
- 出差要求
- 工作组织类型（国企 / 公共机构 / 私企 / 外企 / 公益组织）
- 地理分布（全国性 / 仅限特定地区）

**搜索关键词**：

```
<岗位名> 工作时长 加班
<岗位名> 出差 频率
<岗位名> 办公环境
<岗位名> 国企 vs 外企
<岗位名> 一线城市 占比
```

### 3.6 发展前景

- 进入该行业的常见方法
- 该职业 / 行业的发展前景
- 晋升机会与职业阶梯（从哪开始？什么时候达到什么位置？）
- 工作的稳定性

**搜索关键词**：

```
<岗位名> 晋升 路径
<岗位名> 职级 P5 P6 P7
<岗位名> 35 岁 转型
<岗位名> 稳定性
<岗位名> 入行 方法
```

## 第 4 节：城市调研维度（v1.1 新增）

**仅当学生在 Stage 2 填写了具体意向城市时执行。**

参照第三 part「地域信息」清单，每个意向城市覆盖三个方面。

### 4.1 人才状况：人才引进政策

- 当地人才需求和供给情况
- 当地的产业结构（如广东 = 电子制造、北京 = 总部经济、杭州 = 数字经济）
- 人才引进政策的具体优惠（落户、补贴、住房、子女教育）

**搜索关键词**：

```
<城市> 人才引进 政策 2026
<城市> 应届生 落户 补贴
<城市> 主导产业
<城市> 人才需求 报告
<城市> 高校毕业生 留存率
```

### 4.2 待遇状况：城市平均薪酬

- 城市平均月薪 / 中位数月薪
- 应届生平均薪资
- **必须结合消费水平 / 生活成本综合判断**（房租、餐饮、通勤）

**搜索关键词**：

```
<城市> 平均工资 2026
<城市> 应届生 起薪 中位数
<城市> 消费水平 房租
<城市> 生活成本 vs 一线
<城市> 房价 收入比
```

### 4.3 发展机会：城市发展规划

- 城市发展宏观趋势
- 主要经济类型（民营 / 国企 / 外企 / 跨国总部）
- 当地《十四五》/《十五五》规划重点
- 与意向岗位 / 行业的匹配度

**搜索关键词**：

```
<城市> 十五五 规划
<城市> 政府工作报告 2026
<城市> 战略性产业
<城市> 区域规划 重点
<城市> <行业> 产业园
```

### 4.4 城市调研要给学生回答的核心问题

写到城市画像章节时，必须明确回答：

1. 这个城市的薪资水位是否能匹配学生填的薪资期望？
2. 这个城市的主导产业 / 重点规划是否包含学生的意向行业？
3. 学生作为应届生，落户 + 补贴 + 房租的实际综合体验是怎样的？
4. 这个城市未来 3-5 年的产业风向是支持还是削弱学生的职业方向？

## 第 5 节：组织（公司）调研维度（v1.1 新增）

**仅当学生在 Stage 2 填写了具体意向公司 / 组织时执行。**

参照第三 part「组织信息」获取方法，采用多渠道交叉验证：

### 5.1 信息渠道（按可靠度排序）

| 渠道 | 用途 |
| --- | --- |
| 官方网站 / 校招官网 | 一手信息：业务介绍、招聘 JD、年报、最新公告 |
| 公司微信公众号 / 微博 / 视频号 | 近期动态、产品发布、组织文化 |
| 看准网 / Glassdoor | 员工评价、薪资匿名数据、面试经验 |
| 脉脉 | 在职员工讨论、组织变动、近况吐槽 |
| 知乎专题 | 深度行业评论（注意发帖时间 > 1 年的要小心） |
| 雪球 / 同花顺（如上市公司） | 财报、业务结构、股价波动 |
| 行业垂直媒体（36 氪、虎嗅、第一财经等） | 公司战略动作分析 |

### 5.2 组织调研必查 7 项

| 序号 | 项目 | 关注重点 |
| --- | --- | --- |
| ① | 行业地位 | 在所处行业的排名 / 市场份额 |
| ② | 商业模式与主营业务 | 它怎么赚钱？主要 SKU / 服务是什么？ |
| ③ | 近三年战略变化 | 是扩张、收缩还是转型？ |
| ④ | 组织文化与氛围 | 加班文化、晋升公平度、新人友好度 |
| ⑤ | 招聘风格 | 校招 / 社招比例、面试流程、笔试难度、对应届生友好度 |
| ⑥ | 福利与薪资 | 校招 package、绩效构成、股票 / 期权 |
| ⑦ | 风险与争议 | 近一年负面新闻、合规风险、组织动荡 |

### 5.3 搜索关键词

```
<公司名> 校招 2026
<公司名> 应届生 待遇 看准网
<公司名> 面试 经历 牛客 / 脉脉
<公司名> 加班 强度 脉脉
<公司名> 战略 转型 2025 2026
<公司名> 财报 业绩
<公司名> 负面 争议
<公司名> 组织架构 调整
```

### 5.4 组织调研要回答的核心问题

写到组织画像章节时，必须明确回答：

1. 这家公司当前是上升、平台还是下行？
2. 学生作为应届生进入这家公司的真实路径是什么（哪个校招通道 / 是否有暑期实习提前批 / 是否接受跨专业）？
3. 这家公司的组织氛围与学生的性格 / 习惯是否匹配？
4. 这家公司未来 3-5 年是否还在学生的目标赛道上？

## 第 6 节：执行步骤建议

每次完整四维调研约 8-12 分钟。建议按以下顺序：

```
1. 行业调研（约 2-3 分钟）—— 看赛道是否正确
   ↓
2. 岗位调研（约 3-4 分钟）—— 看具体要做什么、需要什么
   ↓
3. 城市调研（约 2 分钟，可跳过）—— 看落地环境
   ↓
4. 组织调研（约 2-3 分钟，可跳过）—— 看具体目的地
```

每完成一项就把要点用 1-3 句话记到内部备忘，写正文时直接引用。

## 第 7 节：中场汇报模板（必做）

四维调研完成后，**必须先把核心发现汇报给学生**（200 字内），并询问是否调整方向。模板：

```
我快速调研了你提的岗位 + 行业 + 城市 + 公司，关键发现如下：

【行业】<行业> 当前处在 <周期阶段>；最重要的政策风向是 <政策>
【岗位】<岗位> 招聘门槛是 <学历 + 硬技能 + 软技能>，应届起薪约 <数字>
【城市】<城市> 主导产业为 <产业>；应届人才补贴 <数字>；房价/收入比 <数字>
【组织】<公司> 当前处在 <战略阶段>；校招通道为 <通道>；近一年关键动作是 <动作>

这些信息和你当前的状态（<学期>+<绩点>+<薪资期望>）有 X 个明显落差：
1. ...
2. ...

需要我把规划重心调整一下、或更换岗位 / 城市 / 公司吗？还是按现有方向继续展开？
```

让学生确认后，再进入 Stage 4。

## 第 8 节：网络工具不可用时的降级方案

如果 WebSearch / WebFetch 工具失败或返回空：

1. 明确告诉学生：「网络调研工具暂时不可用，下面的信息将基于我的训练知识（截止 2025 年中），建议你入职前用 Boss 直聘 / 看准网 / 脉脉 / 城市政府网站做二次验证」
2. 在生成的计划书相关章节顶部增加一个明显提示：
   > 「⚠️ 本节信息未经过实时网络验证。建议你按以下渠道交叉核实：[列对应渠道]。」
3. 仍按模板生成所有章节，但避免给出具体薪资数字 / 落户细节——改为「请查询当地最新数据」。
4. 优先生成结构与方法论，而不是具体数据。
