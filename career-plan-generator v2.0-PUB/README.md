# career-plan-generator · v2.0  公开版

> 让 AI 帮中国大学生生成一份**真正定制化**、**带方法论沉淀**、**结尾有温度**、**对话有节奏**、**任何环境必出 Word**的《职业规划成长计划书》。
>
> 对齐《2026 职业规划工坊》+ 国科职规体系全套方法论。

## 这是什么

这是一个 Claude 技能（Skill）。安装后，当学生对 Claude 说「帮我写一份职业规划书」「我是大几学生想做生涯规划」「不要那种笼统的、要落地的」时，Claude 会自动启用此技能，按下列工作流走一遍：

```
读取当前真实日期
  → 基础信息收集（11 轮单独问询：学制 / 学期 / 自述年级 / 院校 / 学校专业 / 学业 / 语言证书 / 行业证书 / 学生活动 / 项目 / 其他补充）
  → 目标信息（6 轮：意向岗位开放填写 / 地点大类 / 具体城市 / 薪资 / 意向公司 / 备选路径）
  → 四维真实网络调研（行业 / 岗位 / 城市 / 组织）
  → 中场汇报 + 落差补充确认（v1.3 新增：给学生一次主动补完信息的机会）
  → 自我认知问询（13 轮：性格 / 习惯 / 当下情绪 + MBTI 选填 + 霍兰德选填）
  → 风格 / 节奏偏好（3 轮）
  → 生成详尽版正文（嵌入 OKR / 时间矩阵 / SCQA / 可迁移能力六大类四套方法论）
  → 第十三章 反思与展望（行业洞察 + 心理准备 + 匹配诊断含霍兰德/MBTI 互参 + 人生红点对话 + 反重复温度信）
  → 方法论速查卡附录
```

全程约 20-30 分钟，输出一份带封面、页眉页脚、章节编号、表格、引用块、温度感结尾的 Word 文档。**所有问题拆分为单一问题，学生体验是"被深度咨询"而不是"填表"**。

## v1.3 升级要点（vs v1.2）

| 模块 | v1.2 | v1.3 |
| --- | --- | --- |
| 学期 / 年级问询 | 把学期和年级合并为「大一上 / 大一下…」预设选项 | **学期只问上 / 下学期；年级由学生自述**——不预设、不替学生猜 |
| 意向岗位问询 | 有少量预设大类选项 | **完全开放填写**——岗位是非常个人化的，必须由学生说，不给"互联网/金融/国企/考公"这种有限选项 |
| 学生活动经历 | 塞在「其他补充」里 | **独立成题**——专门询问社团 / 学生干部 / 竞赛 / 公益 / 兼职 / 实习；直接决定可迁移能力诊断 |
| 中场汇报后 | 仅一句方向确认 | **新增「落差补充确认」环节**——发现现状落差后，主动邀请学生补充遗漏信息，再决定是否进入下一阶段 |
| 对话节奏 | 复合问题，一轮多问 | **拆分为 36 轮单独问询**（Stage 1: 11 轮 + Stage 2: 6 轮 + Stage 4: 13 轮 + Stage 5: 3 轮 + 中场互动 3 轮），允许"延展追问" |
| MBTI 信息 | 无 | **新增 MBTI 选填项 + 第十三章 · 3.3 MBTI 互参子节**（与霍兰德 / 自评三方互参） |
| 章节结构 | Stage 7 拆为 A-F 六节，在主体后突兀延续 | **整体合并为「第十三章 反思与展望」单一章 5 小节**（不再产生第十四 / 十五 / 十六章的尴尬） |
| 章节内部序号 | 用 2.X.1 / 3.1.X / 9.X 等延续主章号写法 | **统一每章内部从 1 开始**——例如第九章下面是「1. 六大类」「2. 岗位映射」「3. 自评矩阵」… |

## 它解决了什么问题

通用 AI 生成的职业规划书有六大顽疾：
1. **通用化** —— 换个名字就能用
2. **空中楼阁** —— 不基于真实岗位、行业、城市、公司
3. **可迁移能力缺位** —— 只盯专业技能
4. **缺乏方法论沉淀** —— 给清单但不给可终身使用的工具
5. **缺乏温度** —— 结尾段冷冰冰、千篇一律
6. **对话像填表** —— 一次性问完所有问题，学生没有"被咨询"的感受

本技能用「**分阶段拆轮问询 + 四维网络调研 + 落差补充确认 + 霍兰德 + MBTI + 可迁移能力六大类规划 + 寒暑假 OKR + 嵌入 OKR/时间矩阵/SCQA 三套方法论 + 反重复温度信**」八个动作逐个解决。

## 安装

把整个 `career-plan-generator/` 目录复制到你的 Claude 技能目录：

- Cowork / Claude Desktop（Windows）：
  ```
  C:\Users\<你的用户名>\AppData\Roaming\Claude\local-agent-mode-sessions\skills-plugin\<...>\skills\career-plan-generator\
  ```

## 依赖

- 网络搜索工具（WebSearch / WebFetch）—— Stage 3 四维调研需要
- bash / date 命令（或 env 信息）—— Stage 0 读取当前日期
- Node.js + docx 包 —— 生成 .docx：
  ```bash
  npm install -g docx
  ```
- Node 不可用时自动降级为 Markdown 输出

- 「帮我做一份职业规划成长计划书，要针对我个人情况的」
- 「我大二上学期，想做新媒体运营，意向城市厦门，MBTI 是 ENFP，帮我规划」

## 设计原则

执行此技能的 Claude 始终遵循一条核心心法：

> 「如果换一个学生，这条建议需要改吗？如果不需要——重写。」

加上八条具体纪律：
1. 每句话都要能映射回学生填的某条信息
2. 数字必须具体
3. 动词必须可验证
4. 调研不到的事直接承认，不编造
5. 结尾必须有温度，且每次都不同
6. 时间锚点必须从真实当前学期开始
7. 目标用 OKR 表达，可迁移能力用六大类映射
8. **对话拆轮单问 + 落差后主动邀请补充 + 章节序号每章内部从 1 开始**（v1.3 新增）

## 维护与改进

如果你想优化此技能：
1. 调整 `SKILL.md` 主流程或禁止行为清单
2. 修改 `references/interview.md` 中的问题选项
3. 增补 `references/research.md` 中的搜索关键词或信息源
4. 在 `references/methodologies.md` 中追加更多方法论卡片
5. 在 `references/plan_template.md` 中追加章节或调整自检清单
6. 改 `scripts/build_docx.js` 调整 docx 视觉风格

每次改完，建议跑 3-5 个真实学生测试案例（不同年级 / 院校层次 / 意向岗位 / 性格组合）验证输出质量——特别要测试**同一学生连续生成两次**，验证结尾段是否真的不重复。
